# MetaFlow Demo Dashboard

A lightweight, dependency-free dashboard for **simulating** workflow test outcomes. It does not create Meta accounts or connect to Meta, email inboxes, OTP services, CAPTCHA, or verification systems.

## Run locally
Open `index.html` in a modern browser, or serve this folder with any static web server.

## Features
- Responsive overview and settings pages
- Local-only simulated outcomes: completed, needs review, timed out
- Browser-local history (up to 200 runs)
- CSV export and clear-history action
- No passwords or one-time codes collected

History is stored in this browser's Local Storage. Clearing browser site data removes it. This is a front-end demo, not a production account-management service.
